# 🎬 BANK HEIST — 4K Shorts (2160x3840, 9:16)

## 📱 Формат для Shorts/Reels/TikTok

**Разрешение:** 2160×3840 (4K вертикальное)  
**Соотношение сторон:** 9:16  
**FPS:** 60  
**Длительность:** ~90 секунд

---

## 🚀 Быстрый старт

### Способ 1: Автоматический (рекомендуется)

```bash
# 1. Установка зависимостей
npm install

# 2. Захват 4K кадров (~5700 кадров)
node capture-shorts.js

# 3. Сборка MP4 видео
node build-shorts.js
```

**Результат:** `output/bank-heist-shorts-4k.mp4`

---

### Способ 2: Через OBS Studio (быстрее)

1. Откройте `shorts-4k.html` в Chrome
2. Нажмите F11 (полный экран)
3. В OBS Studio:
   - Создайте сцену с размером **2160×3840**
   - Добавьте захват окна Chrome
   - Настройте запись: **MP4, H.264, 60 FPS**
4. Нажмите ▶ PLAY в анимации
5. Запишите ~90 секунд
6. Остановите запись

---

### Способ 3: Через record.html (браузерная запись)

1. Откройте `record.html` в Chrome
2. Нажмите "🔴 НАЧАТЬ ЗАПИСЬ"
3. Скачается файл `.webm`
4. Конвертируйте в 4K MP4:

```bash
ffmpeg -i bank-heist.webm -vf scale=2160:3840 -c:v libx264 -crf 16 -r 60 output.mp4
```

## ⚙️ Настройки качества

В `capture-shorts.js` можно изменить:

```javascript
const WIDTH = 2160;    // ширина (4K)
const HEIGHT = 3840;   // высота (4K)
const FPS = 60;        // кадры в секунду
const DURATION = 95000; // длительность в мс
```

В `build-shorts.js` можно изменить:

```javascript
'-crf', '16',  // качество (16=высокое, 18=очень высокое, 23=среднее)
'-preset', 'slow', // скорость кодирования (ultrafast, fast, medium, slow, veryslow)
```

## 🐛 Проблемы и решения

**Не хватает памяти при захвате:**
```bash
# Уменьшите разрешение до 1080×1920
const WIDTH = 1080;
const HEIGHT = 1920;
```

**Слишком большой размер файла:**
```bash
# Увеличьте CRF (меньше качество)
'-crf', '23'
```

**Puppeteer не запускается:**
```bash
npx puppeteer browsers install chrome
```

**FFmpeg не найден:**
- Windows: скачайте с ffmpeg.org, добавьте в PATH
- Mac: `brew install ffmpeg`
- Linux: `sudo apt install ffmpeg`
