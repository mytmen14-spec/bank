# 📦 Загрузка в Hyperframe / Remotion / подобные сервисы

## Что загрузить

Для конвертации в видео через сервис типа Hyperframe, Remotion, или аналогичные, 
загрузите **всю папку `video-export/`** целиком.

### Основные файлы:

| Файл | Назначение |
|------|-----------|
| `index.html` | Главная анимация (открывается в браузере) |
| `record.html` | Анимация с кнопкой записи через MediaRecorder |

### Вспомогательные файлы:

| Файл | Назначение |
|------|-----------|
| `capture.js` | Скрипт для Puppeteer (захват кадров) |
| `build-video.js` | Скрипт для FFmpeg (сборка MP4) |
| `package.json` | Зависимости Node.js |
| `setup.bat` / `setup.sh` | Скрипты настройки |

---

## Если сервис принимает только HTML

Загрузите **только `index.html`** — он полностью автономный:
- Three.js загружается с CDN
- GSAP загружается с CDN
- Шрифты загружаются с Google Fonts
- Весь CSS и JS встроены в файл

⚠️ Нужен интернет для загрузки CDN-библиотек!

---

## Если сервис принимает проект

Загрузите всю папку `video-export/` с подпапками `frames/` и `output/`.

---

## Альтернатива: записать локально

Если сервис не подходит, используйте локальную запись:

### Вариант A: Через record.html
1. Откройте `record.html` в Chrome
2. Нажмите "НАЧАТЬ ЗАПИСЬ"
3. Скачается файл `.webm`
4. Конвертируйте: `ffmpeg -i file.webm -c:v libx264 output.mp4`

### Вариант B: Через запись экрана
1. Откройте `index.html` в Chrome (на весь экран, F11)
2. Запустите запись экрана
3. Нажмите ▶ PLAY
4. Дождитесь окончания
5. Остановите запись

### Вариант C: Через Puppeteer (лучшее качество)
```bash
npm install
npm run export
```
Результат: `output/bank-heist.mp4`
